# Final Project - Emotion Detection Application

This is a web application developed using Flask and Python. It utilizes Watson NLP Emotion Predict service to detect emotions (anger, disgust, fear, joy, sadness) from text statements.

## Features
- AI-based emotion detection using Watson NLP
- Packaged Python module (`EmotionDetection`)
- Flask web interface
- Unit testing with `unittest`
- Code quality adhering to PEP8 standards (10/10 pylint score)
